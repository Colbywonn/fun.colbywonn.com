# fun.colbywonn.com

Toys, lists, and side projects by Colby Miller. A sister site to [colbywonn.com](https://colbywonn.com), built with Jekyll and hosted on GitHub Pages.

## Layout

| Path | Contents |
| --- | --- |
| `index.md` | Homepage |
| `_data/pages.yml` | The site's pages: nav, homepage cards, and which are still "coming soon" |
| `_layouts/default.html` | The page layout: header, nav, footer |
| `assets/css/site.css` | All styles |
| `assets/fonts/` | VT323 and IBM Plex Mono |
| `assets/img/board.svg` | The circuit-board background |
